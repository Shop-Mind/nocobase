# 创意工坊 1:1 对标 · 完整功能规划(2026-07-07)

> 目标:把「AI 改图」从「候选区 + 抽屉快捷」升级为**对标阿里巴巴国际站官方「创意工坊」的独立工具页**,功能设计逐项对齐。
> 依据:官方创意工坊 14 个功能的实拍 UI(用户提供)+ 前序 API 调研(`2026-07-07-alibaba-creative-workshop-research.md`)+ 补充调研(智能视频/推荐提示词/选区/模型档/比例)。
> 本文是**规划**,不是实现;待评审确认后分阶段落地。已建能力(候选区/采纳/发布采纳集/9 个 instruct 场景/gpt-image-2 通道)全部复用,不推倒。

## 一、官方创意工坊全貌(实拍还原)

**布局**:独立全屏工具页(`post.alibaba.com` 发布页里弹出),不是塞在表单里。
- 顶部 tab:**智能图片 / 智能视频**。
- 左侧**功能图标栏**(竖排 14 项):白底图 / 场景图 / 图片擦除 / 商品换色 / Logo定制 / 模特图 / 高清图 / 细节图[新] / 指令生图 / 图片翻译[新] / 换材质[新] / 生产流程图[新] / 营销卖点图[新] / 图片改尺寸。
- 中间:**该功能的专属表单**(每个功能表单不同)。
- 右侧:**示例预览**(该功能的「前后对比」样例大图)。

**每个功能通用的元素**:
- `上传商品图片 (1/9)`:支持**多图**(最多 9 张),缩略图 hover 出「查看大图 / 删除图片」(部分功能还有「设置选区」)。
- 底部:`每个原图生成张数 [1~N]` + `使用模型 [基础版 / 进阶版]` + `预计消耗 X i豆` + `开始生成`。
- 部分功能:`图片比例`(1:1 / 2:3 / 3:2 / 3:4 / 4:3 / 4:5 / 5:4 / 9:16 / 16:9 / 21:9,按「渠道 常用」分组)。
- 部分功能:**设置选区**(涂抹/框选出商品主体或换色区,mask)。

**一条关键交互**:**点击/上传图片后自动生成推荐提示词**(场景图里「推荐提示词」给 3 条基于该商品图的场景描述,可「填入」;也可「换一换/重新生成」)。

## 三、跨功能能力(官方都有,我们要补)

> 细节见补充调研 `2026-07-07-alibaba-creative-workshop-research-supplement.md`。

1. **多图上传(1/9)+ 批量**:一次最多 9 张,逐张生成候选。我们已有多选,扩到工坊页多图上传。
2. **每个原图生成张数**:已有(数量选择器)。
3. **模型档位(基础版/进阶版)+ i豆计费**:i豆 ≈ ¥0.2/豆;文本不耗豆,图片/视频/场景耗豆。**基础版 ≈ 标准/flash 档**(白底 7、高清 3——便宜,底层是分割/超分),**进阶版 ≈ pro/plus/max 高分辨率档**(场景 51——贵,高算力生图)。我们:模型下拉已支持显式选模型;进一步做「基础/进阶」语义档 → 映射到具体模型(测试期都指 gpt-image-2,生产映射万相/qwen 标准 vs pro)。
4. **图片比例(10 档)**:端点用 **`size="宽*高"`(不是 aspect_ratio)**。`qwen-image-max/plus` 只有 5 个固定档(如 16:9=1664×928),覆盖 1:1/16:9/9:16/4:3/3:4;**2:3/3:2/4:5/5:4/21:9 需走 `qwen-image`(512–2048 自定义)或 `wan`(1:8~8:1)**;21:9 超宽只能自定义档。editImage 的 hd `sizeStrategy` 已是雏形,扩成通用 `size` 透传 + 档位→尺寸映射表。
5. **设置选区(mask)**【难点,单列阶段 P3】:契约=前端产出**与原图等分辨率的二值 mask**(白=改、黑=留)→ 喂 `description_edit_with_mask`(`mask_image_url`)/`image-erase-completion`/`vary_region`。产 mask 两条路:**①canvas 手动涂抹/框选**(自研,先做);**②VIAPI imageseg `SegmentCommodity`(`ReturnForm=mask`)自动点选主体**(SAM 式,后补)。注:百炼本身不暴露 SAM 点/框交互;**白底图本质就是 `SegmentCommodity(whiteBK)`**。
6. **点击图片自动生成提示词**:就是 **qwen-vl / qwen3-vl 多模态图生文**(`MultiModalConversation` 或 OpenAI 兼容 chat),传商品图 + 一句指令 → 出 3 条场景/卖点 prompt;**无独立 image-to-prompt 端点**。别和生图端点自带的 `prompt_extend`(文→文改写)混淆。新增服务:`aiListingMedia:suggestPrompts({assetId, scene, n})`。
7. **模版库**:场景图风格模版、营销主题模版、Logo 工艺、模特库 —— 预置资源(env/DB 配)。
8. **智能视频**(后置 P6):见第六节 P6。

## 六、分阶段规划(可执行可验收)

- **P0 地基**(✅ 已完成):候选区闭环 + 采纳集优先 + 9 场景 + 快捷/模型/数量 + 抽屉桥接 + gpt-image-2。
- **P1 工坊页骨架 + instruct 系九功能专属表单**:建独立工坊页(功能栏+表单+预览);白底/场景/擦除/换色(先不带选区,用指令)/高清/换材质(先 prompt)/指令/细节(先裁剪+超分)/改尺寸,各自专属最简表单 + 比例 + 张数 + 模型档。验收:每功能有独立表单,能出候选并回候选区采纳。
- **P2 推荐提示词 + 图片比例透传**:`suggestPrompts`(qwen-vl 看图出 3 条);editImage 支持 `size/aspect`。验收:场景图能「一键推荐 3 条」并填入;比例生效。
- **P3 选区(mask)**:前端涂抹/框选出 mask;换色/细节/换材质走 `description_edit_with_mask`。验收:框选区域换色只改选区。
- **P4 特殊流程(需公网 URL/多图/预置库)**:图片翻译(`qwen-mt-image`)、模特图(`virtualmodel-v2` + 模特库)、Logo定制(Logo图+工艺库)。**前置**:商品图落公网可访问对象存储(签名 URL)管线。验收:中文详情图一键翻英;模特图出图;Logo 贴到商品。
- **P5 生产流程图 + 营销卖点图**:图文混排/模版库/卖点 AI 提取(卖点提取=qwen-vl 看图)。验收:出信息图/卖点图。
- **P6 智能视频**(顶部第二 tab)。官方聚合 4 类,建议按此优先级:
  1. **图生视频**(单图→视频,最通用):`wan2.2-i2v` / `wan2.6-i2v-flash`(便宜) / `wan2.7-i2v`(高质);端点 `.../video-generation/video-synthesis` 异步;720P/1080P、2–15s、画面比 1:8~8:1。
  2. **首尾帧生视频**(双图):wan2.2 首尾帧系列。
  3. **文生视频**(纯文字):wan/wanx t2v。
  4. **数字人口播**(单图+音频):`wan2.2-s2v`;低成本 EMO、长视频 LivePortrait、真人改口型 VideoRetalk。

## 七、关于「场景图点击后按钮消失」

- **现象根因**:抽屉里的快捷按钮用 plugin-ai 原生 `role:'task'` 机制;点任一按钮 → `triggerTask` 把会话**重置为仅问候语**,task 消息(整排按钮)被丢弃 → 按钮消失。这是 plugin-ai 既定行为,桥接层改不动。
- **结论**:抽屉不是承载这 14 个功能的正确形态。本规划用**独立创意工坊页**(每功能常驻专属表单,不会消失)取代抽屉按钮。抽屉回归「自由对话找美工」。
- **过渡**:P1 落地前,若要抽屉按钮不那么突兀,可把无参场景(白底/去logo/高清)设 autoSend(点了直接出图,有反馈),有参场景(场景/换色/换材质)保留「填入提示词让用户补全」。但这只是权宜,最终由工坊页解决。

## 九、关键结论速记(供实施对齐)

1. **改尺寸 ≠ 高清**:改尺寸是**扩图外补画布**到目标平台比例(outpainting,`image-out-painting` 带 output_ratio),高清是**纯放大清晰度**(super_resolution)。两个独立功能。
2. **比例用 `size="宽*高"`**,不是 aspect_ratio;10 档里 5 档固定档(qwen-image-max/plus)可命中,另 5 档(含 21:9)需自定义档(qwen-image / wan)。
3. **推荐提示词 = qwen-vl 图生文**,不是特殊端点;别和 `prompt_extend`(文改文)混。
4. **mask 契约 = 等分辨率二值图**(白改黑留);产 mask 先自研 canvas 涂抹,后接 VIAPI SegmentCommodity 自动点选。
5. **i豆 ≈ ¥0.2/豆**;基础版≈flash/标准、进阶版≈pro/plus/max;耗豆随分辨率/算力(白底 7、高清 3 便宜,场景 51 贵)。
6. **视频分 4 类**(图生/首尾帧/文生/数字人),优先图生视频(wan i2v),主图视频另走 VIAPI 模板剪辑。
