# 图片编辑工作台 · UX 重构方案（2026-07-07）

> 针对预览编辑页「AI 候选区」（Phase 2 已实现）的三点使用反馈做界面重构。
> **只重构前端交互与布局,不改动已验证的服务端能力**(scenes / generate / adopt / discard / candidates + 发布采纳集优先,均 E2E 绿)。
> 配套可视化:`docs/plans/mockups/media-studio-mockup.html`(本地浏览器打开即可预览)。

## 二、设计目标

1. **一屏成事**:选原图 → 改 → 比 → 采纳,动线不断裂、不来回滚动。
2. **原图与候选常驻同框**:并排 / 拉帘可切,所见即所得,不再藏在弹窗里。
3. **相册式管图**:主图组、详情图组分区清晰,运营像管理商品相册一样管图。
4. **全中文 + 场景图标**:场景用图标卡片(对标阿里创意工坊),一眼选。
5. **不侵入**:预览编辑页其它区域(标题/SKU/属性/描述)保持不变;服务端零改动。

## 三、方案:内嵌候选区(轻)+ 原生抽屉(重)

**核心决策(已定):AI 改图直接复用 plugin-ai 原生抽屉,不复刻任何员工/模型/会话 UI。**
职责拆两半:
- **候选区(内嵌预览编辑页)** 只做抽屉做不了的:商品图集(多选)+ AI 候选 + 原图↔候选对比 + 采纳/弃用 + 2–3 个最常用「快捷直连」。
- **AI 改图 = 原生抽屉**:复杂 / 批量 / 多轮 / 换材质等都点「🎨 找美工改图」→ 打开原生抽屉,选中图注入、美工员工 `lst-ivy`、场景做成抽屉快捷按钮。产物回流候选区,双端同步。

### 3.1 入口
- 候选区头部:**「🎨 找美工改图」**主按钮(打开原生抽屉)+ **候选数徽标** + **快捷直连**一排(⬜白底图 / 🧽去logo水印 / 🔍高清,选中图上点了直接出候选)。
- gallery 每张缩略图 hover 也出「🎨 改图」小按钮 → 以该图为源打开抽屉。
- **移除当前塞在中段的旧候选区整块**,换成下面这个横向紧凑版。

### 3.2 候选区布局(内嵌,横向两栏,不再是全高抽屉)

放在预览编辑页原候选区位置(图集/SKU 行下方),整块 Card,横向两栏——比原来那个竖排拉长的版本矮而宽,一屏看得全:

```
┌ AI 候选区 · CM 红外测温仪   [🎨 找美工改图]  快捷: [⬜白底][🧽去logo][🔍高清]  [已选 3 张] ┐
│ ┌──── 图片(多选) ────┐ ┌──────────────── 对比 / 候选 ─────────────────┐ │
│ │ [全部|主图|详情]     │ │      原图              候选                    │ │
│ │ 主图(6)  ▣ ▣ ▣     │ │ ┌──────────┐   ┌──────────┐                 │ │
│ │ 详情图(20)          │ │ │          │ ↔ │          │  [并排 | 拉帘]    │ │
│ │  ☑▣ ☑▣ ▣ ☑▣       │ │ │  原图     │   │  候选     │                 │ │
│ │  ▣ ▣ ▣ ▣          │ │ └──────────┘   └──────────┘                 │ │
│ │  [勾选框多选]        │ │  #1547·详情图   候选·白底(logo已去)           │ │
│ │  角标 主图/已采纳/候选│ │  候选条: [候1] [候2*]                        │ │
│ │                    │ │  [ ✓ 采纳这张 ▾ ]  [ 以此再改 ]  [ 弃用 ]      │ │
│ └────────────────────┘ └───────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────────┘
        点「找美工改图」/hover改图 → 右侧滑出原生抽屉(真员工/模型/会话/快捷能力)
        员工在抽屉里产候选 → 本候选区自动刷新 → 你在这里采纳
```

### 3.3 左栏 · 图片导航(多选)
- Tab:全部 / 主图 / 详情图;按组列缩略图,角标 `主图` / `已采纳`(绿) / `候选N`(蓝)。
- **单击** = 选为「当前图」(进对比区 + 作为快捷改图源)。
- **勾选框多选** = 批量对象:勾多张后头部显示「已选 N 张」,「快捷直连」与抽屉对话都对整批生效。

### 3.4 右栏 · 对比 / 候选(核心,解决反馈 3)
- 未生成:只显示当前原图大图 + 元信息。
- 生成后:**原图 ↔ 候选常驻并排**;`[并排 | 拉帘]` 切(hd/expand 默认拉帘)。
- 多候选:候选缩略条,点选切换对比对象。
- 操作:**采纳这张**(追加为新图 / 替换指定图,替换主图提示白底合规)、以此再改、弃用。

### 3.5 AI 改图 = 原生抽屉(解决反馈 2,复用不复刻)
点「🎨 找美工改图」(或 hover「改图」)→ 打开 **plugin-ai 原生抽屉**(就是你平时那个):
- 真员工(默认美工 `lst-ivy`)、真模型选择、会话、流式、切换——**全用现成的,零复刻**。
- 打开时经 `assistant-bridge` 把**选中图(单/多,序号+地址)注入 system**,并默认这个员工。
- 员工的**场景能力做成抽屉快捷按钮**(⬜白底 🧽擦除 🎨换色 …,plugin-ai 现成的 `role:'task'` 按钮机制,点一下预填指令);也能自由说「这 3 张都去 logo,主图换白底」。
- 员工调 `aiListingEditImage`(Phase 1 已通)产候选 → 候选**回流候选区自动刷新** + 气泡 markdown 预览,双端同步。
- **快改 vs 抽屉分工(已定)**:候选区放 **2–3 个最常用快捷直连**(白底/去logo/高清,秒级、不开对话);**复杂 / 批量 / 多轮 / 其它场景**一律去抽屉找员工聊。

### 3.6 场景中文化(反馈 2,可独立先上)
- 候选标签、快捷按钮:`MediaStudio.tsx:312` 用 key→中文映射(`scenes-meta.ts`);抽屉快捷按钮文案取中文场景名。
- 场景 key → `{ icon(emoji), label(中文) }` 映射(前端 `scenes-meta.ts`)。
- 可选:服务端 `scenes` action 直接按 `X-Locale` 返回中文 `label`(更稳,免客户端翻译)。

## 四、交互流程(运营视角)

**快捷直连(单张,最快)**
1. 预览编辑页选中商品 → 候选区左栏单击一张详情图(成为当前图+源)。
2. 头部快捷点「⬜ 白底图」(或「🧽 去logo」「🔍 高清」)→ 直接生成候选,不开对话。
3. 右栏 **原图 ↔ 候选并排**,一眼比对 → 「✓ 采纳这张 → 追加为新图」→ 进发布图集,左栏该图多「已采纳」角标。
4. 不满意 → 「以此再改」/「弃用」。

**复杂 / 批量 / 多轮(找员工聊)**
1. 左栏勾选多张(如 3 张详情图)→ 头部「已选 3 张」→ 点「🎨 找美工改图」。
2. 右侧滑出**原生抽屉**,美工 Ivy 已就位、选中图已注入;点抽屉快捷按钮「白底」或直接说「这 3 张都去 logo,主图再换白底」。
3. 员工逐张调改图工具产候选 → **候选区自动刷新**出现候选 + 抽屉气泡 markdown 预览(双端同步)。
4. 多轮增量「第 2 张再亮一点」基于上一候选继续改。
5. 回候选区逐张对比、采纳。全程只产候选,采纳权始终在你。

6. 发布时自动用采纳集(已实现,采纳集优先)。

## 六、分步骤(可执行可验收)

- **Step 1｜场景中文化 + `scenes-meta`**(独立,先上):候选标签/快捷用中文+图标。验收:无英文场景名。
- **Step 2｜候选区横向两栏重排**:左图集(多选)+ 右对比/候选常驻并排/拉帘 + 采纳/以此再改/弃用;替换旧内嵌块。验收:一屏看全,原图候选同框,采纳后刷新。
- **Step 3｜快捷直连**:头部 2–3 快捷(白底/去logo/高清)对当前图/已选批量直接 generate(带日限额、进度)。验收:点白底秒级出候选。
- **Step 4｜美工员工 lst-ivy + 抽屉桥接**:seed 员工;`openEditor` 打开原生抽屉、注入选中图、场景做快捷按钮;候选回流候选区自动刷新。验收:点「找美工改图」开抽屉,说「去 logo」出候选并回流页面。
- **Step 5｜浏览器闭环验收**:真实 Key 走「快捷白底→并排→采纳」+「多选找员工批量去 logo→回流→采纳」,记录截图与验收。

## 七、最终决策(已定,供实施对齐)

| 项 | 决定 |
|---|---|
| AI 改图形态 | **直接用 plugin-ai 原生抽屉**,不复刻员工/模型/会话 UI |
| 候选区形态 | **内嵌预览编辑页**,横向两栏(图集多选 + 对比/候选) |
| 快捷 vs 抽屉 | 候选区放 **2–3 个最常用快捷直连**(白底/去logo/高清,秒级);**复杂 / 批量 / 多轮 / 其它场景**去抽屉找员工聊 |
| 对话员工 | 本轮 seed 美工 `lst-ivy`,「找美工改图」当场可用 |
| 批量上限 | 建议一次 ≤10 张(受日限额保护);如你有别的数,告诉我 |
