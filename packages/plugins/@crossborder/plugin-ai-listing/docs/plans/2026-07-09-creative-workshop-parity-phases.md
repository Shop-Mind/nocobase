## 一、本轮新调研增量（对上轮两篇的补充）

来源确定度标注沿用：【官方】通稿/官方文档；【API】Aidge 官方 API 文档（Wayback 存档抓取）；【文章】第三方教程/实测；【未确认】公开渠道查不到。

1. **集成架构**【API】：阿里创意工坊底层是 Aidge（阿里国际 AI 开放平台）的 iframe 编辑器
   （`image-editor.aidc-ai.com` + postMessage 协议）。我们不需要 iframe——工坊本就是自己的 React 组件，
   这条只说明「阿里的工坊也是产品化封装，不存在我们摸不到的黑魔法」。
2. **场景图 API 规格**【API】：`/ai/image/background/generation/scenario`——输入 512²~3000²；
   `modelNum`（场景模版 ID）；`needLayout`（是否允许重排商品构图）+ `productTitle`；**API 侧输出仅
   1:1（800×800）与 3:4（750×1000）两档**；单任务 2–10 张（默认 4）。配套
   `Scene Recommendation and Query API`：按商品 title/image/category 推荐场景模版。模板量 700+ → 1000+【官方】。
3. **模特系 API 规格**【API】：模特换肤——人种 4 选一（WHITE/BLACK/YELLOW/BROWN）、性别 2、年龄 3 档
   （青年 20-30/中年 30-50/老年 60+）、背景=保留原背景或 4 场景（**影棚/室内/欧洲街景/海滩**）、张数 1-4；
   虚拟试穿（平铺服装+模特库/自传模特）；Prompt2Model（文字生成自有模特，比例 9 档）。
4. **图片翻译 API 规格**【API】：源/目标语言（ISO 639-1，68→198 种）；**「是否翻译商品主体上的文字」**、
   **「品牌词保护（默认不译）」**两个开关；`useImageEditor` 可回图层数据供二次编辑。
5. **商品换色**【官方】：上传基础图 → **框选/点选色块区域** → 选目标颜色集合 → **一键批量生成全部颜色的
   SKU 图组** → **自动回填商品发布表单（按 SKU 维度）**。
6. **自定义模版**【文章】：= 生成出好效果后点「**保存为模版**」沉淀入个人模板库，同类商品复用保持风格统一。
7. **创作历史**：右上角常驻入口【截图确认】；形态（抽屉/页面）、操作【未确认】。旁证：WOOD 视频有「合成
   记录」（任务列表+下载）；Pic Copilot 历史可下载/再次编辑。
8. **i豆计费**【文章，中确定度】：白底 4 豆/张、场景高阶 10 豆/张（另一数据点：进阶版 3 张 51 豆≈17/张，
   存在时间/档位差）；出口通 AI 赠 3000 豆/月、金品 9000/月；约 0.2 元/豆。→ 结论：**做成可配置价目表**，
   不硬编码任何单价。
9. **生成结果交互**【文章】：结果区「**二次编辑、重新生成、保存为模版**」一字排开；成图**无水印下载**。
10. **智能视频 tab 的功能清单：未确认**。体系内已确认的视频能力池：营销视频（数字人 1000+ 面孔、29 语种）、
    视频翻译（40+ 语种、擦除原字幕重配音）、视频擦除、主图视频（WOOD 模板剪辑）、服装短视频（Pic Copilot）。
11. **其余未确认项**（需真实后台实测补齐）：换材质/生产流程图/营销卖点图/细节图的具体输入输出、换色目标色
    的选择交互、Logo 位置是否可拖拽、基础/进阶版对应的底层模型、逐功能价目全表。

### F. 我们已领先的地方（对齐时**不回退**）

1. **商品图自动带入**（主图+详情图免上传，勾选即用）——阿里要手动上传，我们更顺。
2. **推荐提示词是真 AI 看图**（qwen-vl/gpt 系看商品图出词），阿里推断为静态类目文案。
3. **比例 10 档**——阿里场景图 API 侧只有 1:1 / 3:4 两档。
4. **显式模型选择 + 自动选模**（阿里只有档位）。
5. **候选→对比→采纳→审计→发布采纳集**完整闭环（阿里的「自动回填表单」我们的类比且更受控）。
6. 生成任务**队列化**（候选区侧）、限额保护、撤销采纳。
