## 一、实拍确认的事实（按视觉杀伤力排序）

### 1. 左右栏 sticky 失效 —— 下半页两侧是大片空白死区 🆕（实拍新发现）

滚过媒体卡后（SALES/属性/描述区），**左侧商品列表和右侧生命周期/变更记录整体滚走**，页面下半部分只剩中栏 1010px 内容，两侧共约 450px 纯空白。这是「越往下越难看」的最大来源。

原因：antd `Row` 下各 `Col` 高度只随自身内容（Row 未拉伸对齐），左右栏的 `position: sticky` 没有可滑行的父容器高度，等于没写。代码注释声称「左右两栏 sticky 跟随视口」，实现并未生效。

### 2. 设计字体从未加载 —— 所有衬线数字是 Times（浏览器内实测坐实）

- `document.fonts` 实测：`loadedFaces=[]`，网络请求中字体资源 **0 条**；canvas 宽度比对确认 `Fraunces` / `Instrument Sans` 均解析不到真字体。
- 实拍可见：SALES 的 `$1.2 / $0.76 / $0.62`、变更记录的 `1.56 → 1.21`、分页页码、店标「Q」——全部是 **Times New Roman** 回退。demo 里最有辨识度的 Fraunces 衬线数字在线上是零。
- `creative-console.ts` 引用 Fraunces 22 处、`@font-face` 0 处；jsBlock 注入 CSS 同样 0 处。
- 生产在国内，Google Fonts 不可达 → **必须 woff2 自托管进插件静态资源**。

### 3. 右栏实测 178px —— 信息结构放不下，字中折行

实测三栏宽度：**左 238px / 中 1010px / 右 178px**（1680 视口）。右栏实拍出现「商品状/态」「发布描/述」「发布标/题」字中折行，过滤 chips（全部/人工/AI/系统）竖排堆叠。demo 的右栏约 300px。

之前在 antd 24 格里反复调 `lg=3/4/5` 的震荡，根源是 **24 格粒度太粗**（一格 ≈70px）。demo 本身就是固定像素三栏。

### 4. Header（商品标题区）是 antd 默认件混搭

实拍：标题为纯文本 + 一排 5 枚默认色 Tag（字段已锁定/已发布/源站在售/Dust Bags/起订 100 Piece）+ 右侧头像、🔍发布前检查、PC Switch、退回编辑散排。demo 是 hero 标题卡：20px 大输入框 + 焦点光环 + chip 语言 + 深色「退回编辑」+「98/128 ✓合规」计数。两种气质。

### 5. 媒体卡内部空间失衡

实拍（首屏）：
- stage 大图偏右上，而「候选 · 点候选→原图」提示与三个主操作（**采纳选中候选 / 以此再改 / 弃用**）挂在左侧图集列底部——**操作按钮和它作用的舞台在空间上脱节**；
- 白底商品图浮在白卡上没有边界（stage 缺衬底色/描边/阴影）；
- 详情图缩略下方有一条无意义的灰色骨架条；
- 视频缩略是灰块（未取到 poster 帧），demo 是真实首帧 + 时长徽章。

### 6. 反而达标的部分（不用动）

SALES 定价卡（成本档红卡、阶梯价 ≈$ 换算、毛利红字）、ATTRIBUTES 双列属性表（AI 徽标、高亮行）、DESC 分段 pills、SOURCE 折叠三组——**已经非常接近 demo**。中下半部分不是重灾区，问题集中在框架层（字体/三栏/sticky）和首屏（Header/媒体卡）。

## 三、运营快速改图效率（核心工作流）

当前闭环：选图 → 快捷场景 → 等生成 → 对比 → 采纳(+确认弹窗)。骨架对，卡点：

| # | 现状（源码核实） | 优化方向 |
|---|------|----------|
| C1 | 生成中 `disabled={busy}` 禁用全部场景按钮（单飞行） | **任务队列化**：可连续派活，右上任务条显示 done/total/失败 |
| C2 | 采纳过 Popconfirm；无回滚（0 处 revert） | 采纳**免确认 + 可撤销**（toast 撤销 + 变更记录一键回滚） |
| C3 | 失败候选无卡内重试 | 候选卡上「重试」按钮（沿用原参数） |
| C4 | 候选逐张进舞台 | 网格对比视图（2×2 同屏挑图） |
| C5 | 对比只有拉帘/并排，无放大 | 滚轮缩放 + 拖拽平移（去 logo/水印验收需要看细节） |
| C6 | 批量生成 ✓，批量采纳 ✗ | 「采纳全部选中候选」 |
| C7 | 自定义改图必开创意工坊弹窗 | 舞台底部常驻 prompt 行（回车即改） |
| C8 | 操作按钮挂在图集列底部（见事实 5） | 候选条 + 操作条移到 stage 正下方，形成「看图→决策」动线 |

## 四、修正后的优先级路线

### P0 —— 框架层三件套（~2 天，一起做完再看效果）
1. **三栏改固定像素 flex 布局 + 修 sticky**（0.5–1d）：左 250px / 中 flex / 右 250px；左右栏各自 `max-height: calc(100vh - N)` 内部滚动，彻底解决「下半页两侧大白」+「右栏折行」+「24 格来回震荡」三个问题。
2. **字体自托管**（0.5d）：Fraunces 500/600/700 + Instrument Sans 400–700 woff2 进插件资源 + `@font-face`（`font-display: swap`）。一次修复 22 处数字观感。
3. **媒体卡首屏整顿**（0.5d）：stage 加衬底（canvas 色 + 内描边 + 阴影）；候选条/操作条移到 stage 下方（C8）；去掉灰色骨架条；视频缩略取 poster 帧（`video#t=0.1` 或 canvas 抽帧）。

### P1 —— Header hero 化 + 保存安全网（~2 天）
4. **Header 标题卡重构**（1d）：demo 的 hero 卡（大输入框 + chip 行 + 深色退回钮 + 计数「N/128 ✓合规」），顺手收敛 emoji→SVG、antd Tag→皮肤 chip。
5. **B1+B2 保存安全网**（1d）：粘性操作条 + Cmd+S + 未保存拦截。

### P2 —— 效率深化（按价值排序，独立可做）
6. C2 采纳免确认+可撤销（0.5d）→ 7. C1 任务队列化（1.5d）→ 8. C4 网格对比 + C6 批量采纳（1d）→ 9. B3 键盘流（1d）→ 10. C3 重试 / C5 缩放 / C7 常驻 prompt（各 0.5–1d）→ 11. B5 编辑占用（随多人上线再排）。
